# Operator Aritmatika

Python bisa menghitung seperti kalkulator, tapi jauh lebih fleksibel karena hasilnya bisa
disimpan di variabel dan dipakai lagi.

| Operator | Arti | Contoh | Hasil |
| --- | --- | --- | --- |
| `+` | tambah | `7 + 2` | `9` |
| `-` | kurang | `7 - 2` | `5` |
| `*` | kali | `7 * 2` | `14` |
| `/` | bagi | `7 / 2` | `3.5` |
| `//` | bagi bulat | `7 // 2` | `3` |
| `%` | sisa bagi (modulo) | `7 % 2` | `1` |
| `**` | pangkat | `7 ** 2` | `49` |

<Playground initialCode={`print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(7 ** 2)`} />

<Callout type="info">
  Pembagian `/` **selalu** menghasilkan `float`, bahkan `10 / 2` hasilnya `5.0`.
</Callout>

## Bagi bulat dan sisa bagi

`//` dan `%` sering dipakai bersama. Misalnya, 135 menit itu berapa jam dan berapa menit?

<Playground initialCode={`total_menit = 135
jam = total_menit // 60
menit = total_menit % 60
print(jam, "jam", menit, "menit")`} />

`%` juga berguna untuk mengecek bilangan genap: kalau `angka % 2` hasilnya `0`, angkanya genap.

## Urutan pengerjaan

Seperti di matematika, Python mengerjakan `**` dulu, lalu `*`, `/`, `//`, `%`, baru `+` dan `-`.
Pakai **kurung** untuk mengatur urutannya sendiri:

<Playground initialCode={`print(2 + 3 * 4)
print((2 + 3) * 4)`} />

## Menghitung dengan variabel

<Playground initialCode={`harga_nasi = 12000
harga_es_teh = 5000
jumlah_orang = 3

total = (harga_nasi + harga_es_teh) * jumlah_orang
print("Total:", total)
print("Per orang:", total / jumlah_orang)`} />

## Operator penugasan singkat

Menambah isi variabel sangat sering dilakukan, jadi Python punya cara singkat:

| Cara panjang | Cara singkat |
| --- | --- |
| `skor = skor + 10` | `skor += 10` |
| `nyawa = nyawa - 1` | `nyawa -= 1` |
| `harga = harga * 2` | `harga *= 2` |

<Playground initialCode={`saldo = 50000
saldo += 20000
saldo -= 15000
print("Saldo akhir:", saldo)`} />

## Ringkasan

- `+ - * /` bekerja seperti di matematika; `/` selalu menghasilkan `float`.
- `//` membagi lalu membuang desimal, `%` mengambil sisa bagi, `**` memangkatkan.
- Gunakan kurung untuk mengatur urutan pengerjaan.
- `x += 1` adalah cara singkat dari `x = x + 1`.
