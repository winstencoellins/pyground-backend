# f-string

Menyambung teks dan angka dengan `+` dan `str()` cepat jadi berantakan:

<Playground initialCode={`nama = "Rudi"
umur = 20
print("Halo " + nama + ", umurmu " + str(umur) + " tahun")`} />

**f-string** membuatnya jauh lebih rapi. Tulis huruf `f` sebelum tanda kutip, lalu taruh
variabel di dalam kurung kurawal:

<Playground initialCode={`nama = "Rudi"
umur = 20
print(f"Halo {nama}, umurmu {umur} tahun")`} />

Tidak perlu `str()`, Python mengubahnya otomatis.

## Ekspresi di dalam kurung kurawal

Di dalam kurung kurawal kamu bisa menulis perhitungan atau memanggil method:

<Playground initialCode={`harga = 15000
jumlah = 3
nama = "kopi susu"
print(f"{jumlah} {nama.title()} = Rp{harga * jumlah}")
print(f"Tahun depan umurku {17 + 1}")`} />

## Mengatur format angka

Setelah titik dua di dalam kurung kurawal, kamu bisa mengatur tampilan angka:

<Playground initialCode={`total = 1250000
rata_rata = 87.6666

print(f"Total: Rp{total:,}")
print(f"Rata-rata: {rata_rata:.2f}")
print(f"Rata-rata: {rata_rata:.0f}")`} />

| Format | Arti | Contoh hasil |
| --- | --- | --- |
| `:,` | pemisah ribuan | `1,250,000` |
| `:.2f` | 2 angka di belakang koma | `87.67` |
| `:.0f` | dibulatkan tanpa desimal | `88` |

<Callout type="info">
  Python memakai format angka Inggris: koma untuk ribuan dan titik untuk desimal. Kalau ingin
  format Indonesia (`1.250.000`), tambahkan `.replace(",", ".")` pada hasilnya.
</Callout>

<Playground initialCode={`total = 1250000
rupiah = f"{total:,}".replace(",", ".")
print(f"Total: Rp{rupiah}")`} />

<Callout type="warning">
  Jangan lupa huruf `f`. Tanpa `f`, Python menampilkan kurung kurawalnya apa adanya:
  `"Halo {nama}"`.
</Callout>

## Latihan

Buat struk sederhana dengan f-string: nama barang, jumlah, dan total harga dengan pemisah ribuan.

<Playground initialCode={`barang = "Buku tulis"
harga = 4500
jumlah = 12

# Contoh hasil: 12 x Buku tulis = Rp54,000
`} />

## Ringkasan

- f-string: huruf `f` sebelum kutip, variabel atau ekspresi di dalam kurung kurawal.
- Tidak perlu `str()` untuk angka.
- `:,` untuk pemisah ribuan, `:.2f` untuk jumlah angka desimal.
