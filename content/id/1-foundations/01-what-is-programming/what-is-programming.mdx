# Apa Itu Pemrograman?

Komputer itu sangat cepat, tapi tidak bisa menebak maumu. **Pemrograman** adalah cara kita
memberi instruksi yang jelas dan berurutan kepada komputer. Kumpulan instruksi itu disebut
**program**, dan bahasa yang kita pakai untuk menulisnya disebut **bahasa pemrograman**.

Bayangkan kamu menulis resep nasi goreng untuk teman yang belum pernah masak:

1. Panaskan minyak.
2. Masukkan bawang, tumis sampai harum.
3. Masukkan nasi, aduk.
4. Tambahkan kecap dan garam.

Kalau langkahnya tertukar atau ada yang terlewat, hasilnya berantakan. Program juga begitu:
komputer menjalankan instruksi **persis** seperti yang kamu tulis, dari atas ke bawah.

<AnimatedDiagram name="instructions-flow" caption="Komputer membaca instruksi satu per satu, dari atas ke bawah." />

## Kenapa Python?

Python adalah bahasa pemrograman yang tulisannya mirip bahasa Inggris sederhana, sehingga
cocok untuk pemula. Tapi jangan salah, Python juga dipakai profesional untuk membuat aplikasi web,
analisis data, kecerdasan buatan, dan otomasi.

<Callout type="info">
  Di Pyground, kamu tidak perlu meng-install apa pun. Kode Python dijalankan langsung di browser-mu.
</Callout>

## Program pertamamu

Instruksi paling sederhana di Python adalah `print()`, yang menampilkan teks ke layar.
Tekan tombol **Jalankan** di bawah ini:

<Playground initialCode={`print("Halo, dunia!")
print("Aku sedang belajar Python di Pyground")`} />

Coba ubah teksnya menjadi namamu sendiri, lalu jalankan lagi.

<Callout type="tip">
  Teks di Python harus diapit tanda kutip, `"seperti ini"` atau `'seperti ini'`.
</Callout>

<Callout type="warning">
  Python membedakan huruf besar dan kecil. `Print("Halo")` akan error, karena yang benar adalah `print`.
</Callout>

## Di luar browser

Nantinya, saat kamu membuat proyek sendiri, kamu akan menjalankan Python di terminal:

## Ringkasan

- Program adalah kumpulan instruksi yang dijalankan komputer secara berurutan.
- Python mudah dibaca dan dipakai di banyak bidang.
- `print()` menampilkan teks ke layar.
