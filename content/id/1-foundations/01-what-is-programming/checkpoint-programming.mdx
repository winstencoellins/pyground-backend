# Uji Kemampuan: Apa Itu Pemrograman

Saatnya memakai semua yang sudah kamu pelajari di modul ini, **tanpa bantuan**. Tidak ada langkah, tidak ada petunjuk, dan editornya kosong. Baca soalnya baik-baik, rencanakan dulu, lalu tulis programmu sendiri.

- Programmu dicek otomatis. Tekan **Cek jawaban** sesering yang kamu mau.
- Hanya contoh pertama yang ditampilkan. Kalau ada tes tersembunyi, pikirkan kasus lain dan uji sendiri dengan **Jalankan**.
- Contoh jawaban baru terbuka setelah semua tes lulus, supaya kamu bisa membandingkannya dengan caramu.

Kalau buntu, buka lagi pelajaran sebelumnya. Itu bukan curang. Programmer sungguhan juga begitu.

<Exercise
  type="apply"
  title="Kartu perkenalan"
  tests={[
    { output: "==============\nNama : Sari\nKota : Medan\nHobi : Membaca\n==============" },
  ]}
  solution={`print("==============")
print("Nama : Sari")
print("Kota : Medan")
print("Hobi : Membaca")
print("==============")`}
  reflect={"Kalau satu spasi saja berbeda, tesnya gagal. Kenapa komputer seteliti itu, padahal manusia tidak peduli soal satu spasi?"}
>

Cetak kartu perkenalan ini **persis sama**, termasuk spasi sebelum titik dua dan jumlah tanda `=`:

```
==============
Nama : Sari
Kota : Medan
Hobi : Membaca
==============
```

</Exercise>
