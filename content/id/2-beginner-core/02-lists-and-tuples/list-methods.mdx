# Menambah, Menghapus, dan Mengurutkan List

List jarang diam. Daftar belanja bertambah, antrean berkurang, dan nilai perlu diurutkan.
Python menyediakan **method** untuk semua itu.

## Menambah isi

- `append(x)` menambah `x` di **akhir** list.
- `insert(i, x)` menyisipkan `x` di indeks `i`.

<Playground initialCode={`antrean = ["Ani", "Budi"]
antrean.append("Citra")
print(antrean)

antrean.insert(0, "Dodi")
print(antrean)`} />

## Menghapus isi

- `remove(x)` menghapus `x` yang pertama ditemukan.
- `pop()` mengambil sekaligus menghapus isi terakhir. `pop(i)` melakukannya di indeks `i`.

<Playground initialCode={`antrean = ["Dodi", "Ani", "Budi", "Citra"]

antrean.remove("Budi")
print(antrean)

dilayani = antrean.pop(0)
print("Sekarang dilayani:", dilayani)
print("Sisa antrean:", antrean)`} />

<Callout type="warning">
  `remove()` akan memberi `ValueError` kalau isinya tidak ada di list. Cek dulu dengan `in`
  kalau kamu tidak yakin.
</Callout>

## Mengecek isi dengan `in`

<Playground initialCode={`belanjaan = ["beras", "telur", "gula"]

if "telur" in belanjaan:
    print("Telur sudah dicatat")

if "kopi" not in belanjaan:
    belanjaan.append("kopi")

print(belanjaan)`} />

## Mengurutkan

- `sort()` mengurutkan list itu sendiri (list aslinya berubah).
- `sorted(list)` membuat list baru yang terurut, list asli tetap.
- Tambahkan `reverse=True` untuk urutan dari besar ke kecil.

<Playground initialCode={`nilai = [78, 92, 65, 88]

terurut = sorted(nilai)
print("Baru:", terurut)
print("Asli:", nilai)

nilai.sort(reverse=True)
print("Asli setelah sort:", nilai)`} />

<Callout type="tip">
  `sort()` tidak mengembalikan apa-apa (hasilnya `None`). Jadi jangan tulis
  `nilai = nilai.sort()`, karena isi `nilai` akan hilang.
</Callout>

## Fungsi bawaan yang berguna

## Membangun list dari loop

Pola akumulator dari modul sebelumnya juga bisa dipakai untuk list: mulai dari `[]`, lalu
`append()` di setiap putaran.

<Playground initialCode={`nilai = [78, 92, 65, 88, 55, 70]
lulus = []

for n in nilai:
    if n >= 70:
        lulus.append(n)

print("Yang lulus:", lulus)`} />

## Ringkasan

- Tambah: `append(x)`, `insert(i, x)`.
- Hapus: `remove(x)`, `pop()`, `pop(i)`.
- Cek: `x in daftar`, `x not in daftar`.
- Urutkan: `daftar.sort()` (mengubah asli) atau `sorted(daftar)` (membuat list baru).
