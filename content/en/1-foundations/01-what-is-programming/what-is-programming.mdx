# What Is Programming?

Computers are incredibly fast, but they can't guess what you want. **Programming** is how we give
a computer clear, step-by-step instructions. A set of those instructions is called a **program**,
and the language we write it in is a **programming language**.

Imagine writing a fried rice recipe for a friend who has never cooked:

1. Heat the oil.
2. Add the garlic and shallots, stir until fragrant.
3. Add the rice and mix.
4. Add sweet soy sauce and salt.

If the steps are swapped or one is missing, the result is a mess. Programs work the same way: the
computer runs your instructions **exactly** as written, from top to bottom.

## Why Python?

Python reads almost like simple English, which makes it great for beginners. Don't be fooled,
though: professionals use Python to build web apps, analyze data, train AI models, and automate work.

## Your first program

The simplest instruction in Python is `print()`, which shows text on the screen.
Press **Run** below:

<Playground initialCode={`print("Hello, world!")
print("I'm learning Python on Pyground")`} />

Try changing the text to your own name and run it again.

<Callout type="tip">
  Text in Python must be wrapped in quotes, `"like this"` or `'like this'`.
</Callout>

<Callout type="warning">
  Python is case-sensitive. `Print("Hi")` raises an error, because the correct name is `print`.
</Callout>
