# Arithmetic Operators

Python can calculate like a calculator, but it's far more flexible because results can be stored
in variables and reused.

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| `+` | add | `7 + 2` | `9` |
| `-` | subtract | `7 - 2` | `5` |
| `*` | multiply | `7 * 2` | `14` |
| `/` | divide | `7 / 2` | `3.5` |
| `//` | floor division | `7 // 2` | `3` |
| `%` | remainder (modulo) | `7 % 2` | `1` |
| `**` | power | `7 ** 2` | `49` |

<Playground initialCode={`print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(7 ** 2)`} />

<Callout type="info">
  Division with `/` **always** gives a `float`, even `10 / 2` gives `5.0`.
</Callout>

## Floor division and remainder

`//` and `%` are often used together. For example, how many hours and minutes are 135 minutes?

<Playground initialCode={`total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "hours", minutes, "minutes")`} />

`%` is also handy for checking even numbers: if `number % 2` is `0`, the number is even.

## Order of operations

Like in maths, Python does `**` first, then `*`, `/`, `//`, `%`, and finally `+` and `-`. Use
**brackets** to set the order yourself:

<Playground initialCode={`print(2 + 3 * 4)
print((2 + 3) * 4)`} />

## Shorthand assignment operators

Adding to a variable is so common that Python has a shortcut:

| Long form | Shorthand |
| --- | --- |
| `score = score + 10` | `score += 10` |
| `lives = lives - 1` | `lives -= 1` |
| `price = price * 2` | `price *= 2` |

<Playground initialCode={`balance = 50000
balance += 20000
balance -= 15000
print("Final balance:", balance)`} />

## Summary

- `+ - * /` work like in maths; `/` always gives a `float`.
- `//` divides and drops the decimals, `%` gives the remainder, `**` raises to a power.
- Use brackets to control the order of operations.
- `x += 1` is shorthand for `x = x + 1`.
