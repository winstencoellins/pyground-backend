<Exercise
  type="apply"
  title="Three-day piggy bank"
  tests={[
    { output: "Tabungan: 15000" },
  ]}
  solution={`senin = "5000"
selasa = 7500
rabu = 2500.0

total = int(senin) + selasa + rabu
print("Tabungan:", int(total))`}
  reflect={"The three variables have different types: `str`, `int` and `float`. Why does `selasa + rabu` give a `float` even though `selasa` is an `int`?"}
>

Rina wrote down her savings in a messy way. Copy these three variables into your program:

```python
senin = "5000"
selasa = 7500
rabu = 2500.0
```

Then add them up **using those variables** and print exactly:

```
Tabungan: 15000
```

(not `15000.0`)

</Exercise>

<Exercise
  type="apply"
  title="Café price label"
  tests={[
    { output: "Kopi Susu: Rp18000\nStok: 25 gelas" },
  ]}
  solution={`nama = "Kopi Susu"
harga = 18000
stok = 25

print(nama + ": Rp" + str(harga))
print("Stok: " + str(stok) + " gelas")`}
  reflect={"`print(\"Rp\", harga)` puts a space in between. Which ways did you find to get rid of it?"}
>

Create three variables: `nama` holding `"Kopi Susu"`, `harga` holding the number `18000`, and `stok` holding the number `25`. Use them to print:

```
Kopi Susu: Rp18000
Stok: 25 gelas
```

Note: there is no space between `Rp` and the number.

</Exercise>
