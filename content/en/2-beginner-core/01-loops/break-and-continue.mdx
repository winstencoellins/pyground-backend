# `break` and `continue`

Sometimes you need to control a loop from inside: stop early, or skip one round. Python has two
keywords for that.

| Keyword | What it does |
| --- | --- |
| `break` | **stops** the loop completely and moves on to the code after it |
| `continue` | **skips** the rest of this round and goes straight to the next one |

## break: stop right now

<Playground initialCode={`for number in range(1, 11):
    if number == 5:
        print("Found 5, stopping!")
        break
    print(number)
print("Loop finished")`} />

A very common pattern is `while True` with `break`. The loop runs "forever", but stops as soon as
the user types a certain command:

<Playground initialCode={`while True:
    command = input("Type something (or 'quit'): ").strip().lower()
    if command == "quit":
        break
    print("You typed:", command)
print("Goodbye!")`} />

<Callout type="tip">
  `while True` is safe as long as there's a `break` that is **sure** to be reached.
</Callout>

## continue: skip this round

<Playground initialCode={`for number in range(1, 11):
    if number % 2 == 0:
        continue
    print(number)`} />

When `number` is even, `continue` skips the `print()`, so only odd numbers appear.

Another example: counting the vowels in a sentence while skipping spaces.

<Playground initialCode={`sentence = "learning python is fun"
vowels = 0

for letter in sentence:
    if letter == " ":
        continue
    if letter in "aeiou":
        vowels += 1

print("Number of vowels:", vowels)`} />

## Summary

- `break` stops the loop; `continue` jumps to the next round.
- `while True` + `break` is a common pattern for programs that keep asking.
- Both are usually used inside an `if`.
