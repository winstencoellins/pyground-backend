# Looping with `for`

Say you want to show the numbers 1 to 5. You could write `print()` five times, but what about
1 to 1000? That's where **loops** come in.

<Playground initialCode={`for number in range(1, 6):
    print(number)`} />

## How to read it

`for number in range(1, 6):` means: *for each `number` from 1 up to (but not including) 6, run
the block below.*

<AnimatedDiagram name="for-loop" caption="The variable number changes on every pass: 1, 2, 3, 4, 5." />

<Callout type="warning">
  Watch the **indentation** (4 spaces). Indented lines belong to the loop. Forget it and Python
  raises an `IndentationError`.
</Callout>

## More about `range()`

| Code | Result |
| --- | --- |
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |

## Looping over text and lists

`for` isn't just for numbers. You can loop over every character in a string, or every item in
a list:

<Playground initialCode={`fruits = ["mango", "rambutan", "snake fruit"]
for f in fruits:
    print("I like", f)`} />

<Callout type="tip">
  Give loop variables meaningful names. `for f in fruits` works, but `for fruit in fruits` is clearer.
</Callout>

## Summary

- `for` repeats a block of code for each item.
- `range(start, stop, step)` produces a sequence of numbers; `stop` is excluded.
- Indentation defines what's inside the loop.
