# Loop Patterns

Most loops you'll write follow a handful of patterns. Once you know them, writing programs gets
much faster.

## Pattern 1: summing (accumulator)

Create a variable set to `0` **before** the loop, then add to it every round:

<Playground initialCode={`total = 0
for number in range(1, 101):
    total += number
print("1 + 2 + ... + 100 =", total)`} />

## Pattern 2: counting what matches

Similar, but only add `1` when a condition is met:

<Playground initialCode={`multiples_of_three = 0
for number in range(1, 51):
    if number % 3 == 0:
        multiples_of_three += 1
print("Multiples of 3 from 1 to 50:", multiples_of_three)`} />

## Pattern 3: finding the largest value

Keep a "current champion", and replace it whenever you find something bigger:

<Playground initialCode={`exam_scores = [78, 92, 65, 88, 95, 70]
highest = exam_scores[0]

for score in exam_scores:
    if score > highest:
        highest = score

print("Highest score:", highest)`} />

<Callout type="info">
  Python actually has `max()` and `sum()` for this. But understanding the pattern matters, because
  the condition is often more complicated than just "largest".
</Callout>

## Pattern 4: building text

An accumulator can be a string too. Start with an empty string `""`:

<Playground initialCode={`word = "python"
reversed_word = ""
for letter in word:
    reversed_word = letter + reversed_word
print(reversed_word)`} />

## Pattern 5: nested loops

A loop can sit inside another loop. The inner loop runs **completely** for every round of the
outer loop:

<Playground initialCode={`for row in range(1, 4):
    for col in range(1, 4):
        print(f"{row} x {col} = {row * col}")
    print("---")`} />

A visual example: a triangle of stars.

<Playground initialCode={`height = 5
for row in range(1, height + 1):
    print("*" * row)`} />

<Callout type="tip">
  In the triangle example, `"*" * row` replaces an inner loop. When there's a shorter way that's
  still clear, use it.
</Callout>

## Summary

- Accumulator: start at `0` or `""` before the loop, add to it every round.
- Counter: add `1` only when a condition is met.
- Largest value: keep a current champion, replace it when something is bigger.
- Nested loops: the inner loop runs fully for every round of the outer loop.
