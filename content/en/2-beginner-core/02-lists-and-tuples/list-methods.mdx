# Adding, Removing, and Sorting

Lists rarely stay still. Shopping lists grow, queues shrink, and scores need sorting. Python
has **methods** for all of that.

## Adding items

- `append(x)` adds `x` to the **end** of the list.
- `insert(i, x)` inserts `x` at index `i`.

<Playground initialCode={`queue = ["Ani", "Budi"]
queue.append("Citra")
print(queue)

queue.insert(0, "Dodi")
print(queue)`} />

## Removing items

- `remove(x)` removes the first `x` it finds.
- `pop()` takes out and returns the last item. `pop(i)` does the same at index `i`.

<Playground initialCode={`queue = ["Dodi", "Ani", "Budi", "Citra"]

queue.remove("Budi")
print(queue)

served = queue.pop(0)
print("Now serving:", served)
print("Still waiting:", queue)`} />

<Callout type="warning">
  `remove()` raises a `ValueError` if the item isn't in the list. Check with `in` first if
  you're not sure.
</Callout>

## Checking membership with `in`

<Playground initialCode={`groceries = ["rice", "eggs", "sugar"]

if "eggs" in groceries:
    print("Eggs are already on the list")

if "coffee" not in groceries:
    groceries.append("coffee")

print(groceries)`} />

## Sorting

- `sort()` sorts the list itself (the original changes).
- `sorted(list)` returns a new sorted list and leaves the original alone.
- Add `reverse=True` to sort from largest to smallest.

<Playground initialCode={`scores = [78, 92, 65, 88]

ordered = sorted(scores)
print("New:", ordered)
print("Original:", scores)

scores.sort(reverse=True)
print("Original after sort:", scores)`} />

<Callout type="tip">
  `sort()` returns nothing (the result is `None`). So don't write `scores = scores.sort()`,
  or you'll lose your list.
</Callout>

## Handy built-in functions

print("Total:", sum(prices))
print("Most expensive:", max(prices))

print("How many times 5500 appears:", prices.count(5500))

## Building a list in a loop

The accumulator pattern from the last module works for lists too: start with `[]`, then
`append()` on each pass.

<Playground initialCode={`scores = [78, 92, 65, 88, 55, 70]
passed = []

for s in scores:
    if s >= 70:
        passed.append(s)

print("Passed:", passed)`} />

## Summary

- Add: `append(x)`, `insert(i, x)`.
- Remove: `remove(x)`, `pop()`, `pop(i)`.
- Check: `x in my_list`, `x not in my_list`.
- Sort: `my_list.sort()` (changes the original) or `sorted(my_list)` (new list).
