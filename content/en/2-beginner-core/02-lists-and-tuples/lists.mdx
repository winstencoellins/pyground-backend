# Introducing Lists

Imagine writing a shopping list. Creating one variable per item (`item1`, `item2`, `item3`,
...) quickly gets messy. A **list** stores many values in one variable, in order.

## Creating a list

Lists use square brackets `[ ]`, with items separated by commas:

<Playground initialCode={`groceries = ["rice", "eggs", "oil", "sugar"]
scores = [80, 95, 72]
empty = []

print(groceries)
print(scores)
print(empty)
print("Number of items:", len(groceries))`} />

The `len()` you used on strings works on lists too: it gives the number of items.

## Reading items by index

Every item has a position number called an **index**. Just like strings, indexes start at
**0**:

<Playground initialCode={`groceries = ["rice", "eggs", "oil", "sugar"]

print(groceries[0])   # rice
print(groceries[2])   # oil
print(groceries[-1])  # sugar, negative indexes count from the end`} />

<Callout type="warning">
  A list with 4 items has indexes 0 to 3. If you write `groceries[4]`, Python raises
  `IndexError: list index out of range`.
</Callout>

<Playground expectError initialCode={`groceries = ["rice", "eggs", "oil", "sugar"]
print(groceries[4])`} />

## Changing items

Unlike strings, lists **can be changed**. Put the index on the left of `=`:

<Playground initialCode={`groceries = ["rice", "eggs", "oil", "sugar"]
groceries[1] = "flour"
print(groceries)`} />

## Mixed items are allowed

One list can hold different data types, although we usually keep similar data together so
it's easier to work with:

<Playground initialCode={`student = ["Budi", 16, True]
print(student[0], "is", student[1], "years old")`} />

## Looping over a list

You know this from the Loops module. `for` takes the items one at a time:

<Playground initialCode={`groceries = ["rice", "eggs", "oil", "sugar"]
for number, item in enumerate(groceries, start=1):
    print(f"{number}. {item}")`} />

`enumerate()` gives you a running number along with each item, so you don't need your own
counter.

## Summary

- A list stores many values in order: `[item1, item2, ...]`.
- Indexes start at `0`; index `-1` is the last item.
- List items can be changed: `my_list[index] = new_value`.
- `len()` counts the items, and `enumerate()` numbers them while looping.
