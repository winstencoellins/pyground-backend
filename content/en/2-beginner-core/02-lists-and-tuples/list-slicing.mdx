# Slicing and Copying Lists

## Slicing: taking part of a list

Slicing works just like with strings: `my_list[start:end]`. The `end` index is **not
included**.

<Playground initialCode={`months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]

print(months[0:3])   # first 3 months
print(months[3:])    # from index 3 to the end
print(months[:2])    # from the start up to index 2
print(months[-2:])   # last 2 months
print(months[::2])   # every second one: Jan, Mar, May
print(months[::-1])  # reversed`} />

<Callout type="info">
  Slicing never raises an `IndexError`. If the bounds go past the end, Python just takes
  what's there.
</Callout>

## The trap: two names, one list

Look closely at this example:

<Playground initialCode={`a = [1, 2, 3]
b = a
b.append(4)

print("a:", a)
print("b:", b)`} />

`a` changed too! The line `b = a` does **not** create a new list. It only gives the same list
a second name. Think of one box with two labels.

## Copying a list properly

When you want a separate new list, copy it with `copy()` or the slice `[:]`:

<Playground initialCode={`original = [1, 2, 3]
copy1 = original.copy()
copy2 = original[:]

copy1.append(4)
copy2.append(99)

print("original:", original)
print("copy1:", copy1)
print("copy2:", copy2)`} />

## Lists inside lists

A list item can be another list. This is useful for table-like data:

<Playground initialCode={`classroom = [
    ["Ani", 88],
    ["Budi", 75],
    ["Citra", 92],
]

print(classroom[2])      # ['Citra', 92]
print(classroom[2][0])   # Citra

for name, score in classroom:
    print(f"{name}: {score}")`} />

The first index picks the row, the second picks the item inside that row.

## Summary

- `my_list[start:end:step]` takes part of a list; `end` is not included.
- `b = a` doesn't copy, it only adds a second name.
- Copy with `a.copy()` or `a[:]`.
- Lists can contain lists; use two indexes like `data[row][col]`.
