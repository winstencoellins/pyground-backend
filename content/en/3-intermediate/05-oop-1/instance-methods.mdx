# Instance Methods

Objects aren't just containers for data. Through **methods**, an object can also *do*
something with its own data. In this lesson we build a `BankAccount` class that accepts
deposits and withdrawals.

## Methods read the object's data

A method is a function inside a class. Its first parameter is always `self`, so the method can
read the attributes of the object that called it.

<Playground initialCode={`class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def info(self):
        print("Account", self.owner, "balance Rp", self.balance)

budi_acc = BankAccount("Budi", 50000)
ani_acc = BankAccount("Ani", 120000)

budi_acc.info()
ani_acc.info()`} />

When you write `budi_acc.info()`, Python actually runs `BankAccount.info(budi_acc)`. That's why
`self` inside the method holds `budi_acc`.

## Methods change the object's data

Methods can also change attributes. The change is stored on the object, so other methods see it.

<Playground initialCode={`class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        self.balance -= amount

acc = BankAccount("Citra")
acc.deposit(100000)
acc.withdraw(25000)
acc.deposit(10000)
print("Citra's balance:", acc.balance)`} />

## Returning values

Like regular functions, methods can use `return`. That's handy when you need a result, not just
printed output.

<Playground initialCode={`class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        return self.balance

    def can_withdraw(self, amount):
        return amount <= self.balance

acc = BankAccount("Dodi", 30000)
new_balance = acc.deposit(20000)
print("New balance:", new_balance)
print("Can withdraw 40000?", acc.can_withdraw(40000))
print("Can withdraw 90000?", acc.can_withdraw(90000))`} />

## Rejecting bad input with `ValueError`

A negative deposit or a withdrawal bigger than the balance makes no sense. A method should keep
the object's data valid by raising an error with `raise`.

<Playground initialCode={`class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit amount must be more than 0")
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError("Insufficient balance")
        self.balance -= amount

acc = BankAccount("Ani", 50000)

try:
    acc.withdraw(80000)
except ValueError as e:
    print("Failed:", e)

acc.withdraw(20000)
print("Ani's balance:", acc.balance)`} />

If the error isn't caught with `try`/`except`, the program stops. That's better than quietly
storing a negative balance.

<Playground expectError initialCode={`class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit amount must be more than 0")
        self.balance += amount

acc = BankAccount("Budi")
acc.deposit(-5000)`} />

<Callout type="warning">
  Don't forget `self.` when changing an attribute. If you write `balance += amount`, Python
  treats `balance` as a local variable in the method and raises an error, while the object's
  balance stays the same.
</Callout>

## Objects in a list

Objects can be stored in a list like any other value. It's the usual way to manage lots of
records at once.

<Playground initialCode={`class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

customers = [
    BankAccount("Budi", 50000),
    BankAccount("Ani", 120000),
    BankAccount("Citra", 75000),
]

for acc in customers:
    acc.deposit(10000)

total = sum(acc.balance for acc in customers)
print("Total balance of all customers:", total)

richest = customers[0]
for acc in customers:
    if acc.balance > richest.balance:
        richest = acc
print("Largest balance belongs to", richest.owner)`} />

## Summary

- A method is a function inside a class; its first parameter is `self`.
- `obj.method(x)` is the same as `Class.method(obj, x)`.
- Methods can read and change attributes through `self`, and return values with `return`.
- Use `raise ValueError(...)` to reject input that would make the object's data wrong.
- Objects can live in lists and be processed with loops or `sum()`.
