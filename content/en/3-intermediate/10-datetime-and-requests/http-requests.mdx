# Fetching Data from the Internet with requests

Weather apps, Rupiah exchange rates, and the menus in ojek apps all fetch data from a server
over the internet. In this lesson you learn to do the same from Python with the
**`requests`** library.

## What is an HTTP API?

Every time a browser opens a page, it sends a **request** to a server and receives a
**response**. (You'll dig into this in the *How the Web Works* lesson in Stage 4.) An
**HTTP API** works the same way, except the server doesn't reply with a web page but with
**data**, usually in **JSON** format.

An API response has two important parts:

- **Status code**: a number that tells you the result. `200` means success, `404` means not
  found, `500` means the server has a problem.
- **Body**: the content, for example JSON text.

You process that JSON text with the `json` module you already know. Imagine a warung API
sends this text:

<Playground initialCode={`import json

`json.loads()` turns JSON text into Python dicts and lists. Notice that `true` in JSON becomes
`True` in Python.

## Your first request with `requests.get`

`requests.get(url)` sends a GET request and returns a **response** object. This example uses
JSONPlaceholder, a free API for practice:

```python
import requests

response = requests.get("https://jsonplaceholder.typicode.com/todos/1", timeout=10)

print(response.status_code)
data = response.json()
print(data)
print(data["title"])
```

Sample output:

```text
200
{'userId': 1, 'id': 1, 'title': 'delectus aut autem', 'completed': False}
delectus aut autem
```

- `response.status_code` is the status code (`200` means success).
- `response.json()` turns the JSON body straight into a dict or list, just like
  `json.loads(response.text)`.

## Sending parameters and setting a `timeout`

Many APIs accept **parameters** in the URL, such as `?userId=1`. Instead of building the URL
yourself, pass a dict to `params`:

```python
import requests

response = requests.get(
    "https://jsonplaceholder.typicode.com/posts",
    params={"userId": 1},
    timeout=10,
)

print(response.url)
posts = response.json()
print("Number of posts:", len(posts))
print("First title:", posts[0]["title"])
```

```text
https://jsonplaceholder.typicode.com/posts?userId=1
Number of posts: 10
First title: sunt aut facere repellat provident occaecati excepturi optio reprehenderit
```

`timeout=10` means: if the server doesn't reply within 10 seconds, stop waiting. Without a
`timeout`, your program could wait forever if the server hangs. Make a habit of always
setting one.

## Handling errors

Plenty can go wrong: the internet drops, the server is slow, or the address is wrong. A `404`
or `500` status code does **not** automatically become an error. Call `raise_for_status()` so
4xx and 5xx status codes turn into exceptions, then catch them with `try`/`except`:

```python
import requests

try:
    response = requests.get("https://jsonplaceholder.typicode.com/todos/99999", timeout=10)
    response.raise_for_status()
    data = response.json()
    print(data)
except requests.exceptions.Timeout:
    print("The server took too long to reply.")
except requests.exceptions.ConnectionError:
    print("Couldn't connect. Check your internet connection.")
except requests.exceptions.HTTPError as e:
    print("The server replied with an error:", e.response.status_code)
```

```text
The server replied with an error: 404
```

To catch every error from `requests` at once, use their parent,
`requests.exceptions.RequestException`.

A body that isn't valid JSON can also break your program. You can practise the same handling
pattern here with `json.loads()`:

<Playground initialCode={`import json

## Summary

- An HTTP API answers requests with data, usually JSON, plus a status code.
- Install it with `pip install requests`, then use `requests.get(url, params=..., timeout=...)`.
- `status_code` gives the result, and `.json()` turns the body into a dict or list.
- Call `raise_for_status()` and catch `requests.exceptions.RequestException` to handle errors
  safely.
